呼吸與貓咪肥胖的關係

😮‍💨

胸腔受壓

腹部脂肪堆積會向上壓迫橫膈膜，讓貓咪每次呼吸都更費力。

💤

睡眠呼吸問題

肥胖貓咪容易打鼾、睡眠呼吸不順，影響睡眠品質與荷爾蒙代謝。

🦴

關節負擔加重

體重過重讓貓咪不願意跳躍活動，活動量下降形成惡性循環。

🫀

心肺功能下降

長期肥胖增加心臟負擔，心肺功能退化使呼吸更加困難。

促進呼吸與代謝的活動方式

01

互動逗貓棒遊戲

模擬獵物移動，讓貓咪自然進行衝刺與跳躍，提升心肺功能。

  1. 每天至少 2 次，每次 10～15 分鐘
  2. 讓逗貓棒模擬真實獵物：慢移、快衝、躲藏
  3. 觀察貓咪呼吸，喘氣明顯時讓牠休息 2 分鐘
  4. 遊戲結束讓貓咪「抓到」獵物，滿足狩獵本能
  5. 逐週增加遊戲強度，循序漸進
02

垂直空間攀爬

貓跳台與層架讓貓咪垂直移動，是最自然的有氧運動。

  1. 設置多層貓跳台，高度循序漸進
  2. 把零食或玩具放在高處，引導貓咪主動攀爬
  3. 攀爬時需要深層呼吸，自然訓練肺活量
  4. 確保跳台穩固，避免跌落受傷
03

嗅聞覓食遊戲

把飼料藏起來讓貓咪用鼻子尋找，訓練深層鼻呼吸同時消耗熱量。

  1. 將當餐飼料分散藏在家中各處
  2. 使用嗅聞墊或益智餵食器
  3. 覓食過程中貓咪會自然進行深層鼻呼吸
  4. 延長進食時間，避免狼吞虎嚥造成腹脹

幫助呼吸與代謝的食物

以下食物對貓咪安全，有助改善呼吸系統與控制體重

🐟

鮭魚

Omega-3 減少呼吸道發炎，高蛋白低脂，是減重期的理想蛋白質來源。

🍗

雞胸肉

高蛋白低卡，維持肌肉量同時減少脂肪，幫助提升基礎代謝。

🫐

藍莓

少量餵食，抗氧化保護肺泡細胞，可當偶爾的健康零食。

🎃

南瓜泥

高纖低卡，幫助腸胃蠕動，增加飽足感，適合減重期添加。

🥚

水煮蛋白

優質蛋白質，幫助維持肌肉量，避免減重時肌肉流失。

💧

濕食 / 主食罐

高水分幫助代謝，比乾飼料更能維持呼吸道濕潤，減少熱量密度。

⚠️ 貓咪絕對禁止的食物

🧅 洋蔥 / 大蒜（溶血性貧血） 🍫 巧克力（中毒） 🍇 葡萄 / 葡萄乾（腎衰竭） 🥛 牛奶（乳糖不耐） 🍬 木糖醇（低血糖） 🐾 生肝臟過量（維生素 A 中毒）
🐱 貓咪是純肉食動物，蔬菜只能少量添加，蛋白質才是主食核心

日常照護技巧

⚖️ 每週量體重，目標每週減少不超過體重的 0.5%，貓咪減重需更緩慢
🥣 少量多餐，每天 3～4 次，避免一次大量進食壓迫橫膈膜
🚫 絕對不能讓貓咪斷食減肥，可能引發致命的肝脂肪沉積症
🌬️ 定期清潔家中灰塵，減少過敏原，維護貓咪呼吸道健康
🩺 減重前先做健康檢查，排除甲狀腺、心臟等疾病
😴 提供安靜舒適的睡眠環境，良好睡眠幫助荷爾蒙調節與代謝
