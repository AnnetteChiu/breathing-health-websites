呼吸與狗狗肥胖的關係

😮‍💨

肥胖壓迫氣道

頸部脂肪堆積會壓迫氣管，導致呼吸費力、運動耐力下降，形成惡性循環。

🌡️

散熱效率降低

狗狗靠喘氣散熱，肥胖使散熱效率變差，容易中暑、不願意運動。

💤

睡眠呼吸問題

肥胖狗狗容易打鼾、睡眠呼吸中止，影響睡眠品質與代謝。

🏃

運動量不足

呼吸不順讓狗狗不愛動，代謝下降，體重更難控制。

改善呼吸的運動方式

01

慢速散步（鼻呼吸訓練）

讓狗狗保持用鼻子呼吸的步調，避免過度喘氣。

  1. 選擇涼爽時段（早晨或傍晚）
  2. 步速放慢，讓狗狗能閉嘴用鼻子呼吸
  3. 每次 15～20 分鐘，每天 2 次
  4. 若開始大喘氣，立即停下休息
  5. 逐週增加 5 分鐘，循序漸進
02

游泳 / 水中運動

水的浮力減輕關節負擔，是肥胖狗狗最理想的有氧運動。

  1. 選擇淺水區，讓狗狗站得到底
  2. 初次每次 5～10 分鐘，觀察呼吸狀況
  3. 游泳時呼吸節奏自然規律，有助肺活量
  4. 結束後確實擦乾，避免耳道感染
03

嗅聞遊戲（鼻腔訓練）

用鼻子找食物能訓練深層鼻腔呼吸，同時消耗大量腦力與體力。

  1. 把少量零食藏在草地或嗅聞墊中
  2. 讓狗狗用鼻子搜尋，每次 10～15 分鐘
  3. 嗅聞時狗狗會自然進行深層鼻呼吸
  4. 零食熱量計入當天總量，不額外增加

幫助呼吸與代謝的食物

以下食物對狗狗安全，且有助於改善呼吸系統與控制體重

🥦

花椰菜

含蘿蔔硫素，幫助排除肺部毒素，少量蒸熟餵食。

🥕

紅蘿蔔

富含 β-胡蘿蔔素，保護呼吸道黏膜，低卡路里適合減重。

🫐

藍莓

高抗氧化，保護肺泡細胞，可直接當零食餵食。

🐟

鮭魚

Omega-3 減少呼吸道發炎，幫助維持健康體重。

🎃

南瓜

高纖低卡，增加飽足感，幫助控制食量。

🥬

菠菜

富含鐵質，提升血氧攜帶能力，改善運動耐力。

⚠️ 狗狗絕對禁止的食物

🍇 葡萄 / 葡萄乾（腎衰竭） 🧅 洋蔥 / 大蒜（溶血） 🍫 巧克力（中毒） 🥑 酪梨（心臟毒素） 🍬 木糖醇（低血糖） 🦴 熟骨頭（碎裂刺傷）

日常照護技巧

🌡️ 避免在高溫時段運動，氣溫超過 28°C 改為室內活動
🏠 短吻犬種（法鬥、巴哥）需特別注意呼吸，運動量要更保守
⚖️ 每週量體重，目標每週減少不超過體重的 1%
🥣 少量多餐取代一次大量餵食，減少胃部壓迫橫膈膜
💧 隨時提供新鮮飲水，充足水分幫助代謝與呼吸道濕潤
🩺 減重前先諮詢獸醫，確認無心肺疾病再開始運動計畫
