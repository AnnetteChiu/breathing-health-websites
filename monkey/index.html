靈長類呼吸問題與體況影響

🫁

人畜共通呼吸道疾病

靈長類與人類基因相近，對流感、結核病、新冠病毒等人類呼吸道病原高度敏感，需嚴格生物安全。

⚖️

圈養肥胖

活動空間受限與高糖飲食，圈養靈長類肥胖率極高，腹部脂肪壓迫橫膈膜影響呼吸。

😰

心理緊迫與免疫

靈長類智力高，圈養環境不足導致慢性心理緊迫，皮質醇升高削弱免疫力，呼吸道感染風險大增。

💉

麻醉高風險

肥胖靈長類麻醉時呼吸道管理困難，體重控制直接影響所有醫療操作的安全性。

🐒

台灣獼猴特性

台灣特有種，適應力強，但圈養環境下容易因高糖食物過度餵食而肥胖，影響呼吸效率。

🦠

B 病毒（Herpes B）

獼猴特有的皰疹病毒，對人類致命，呼吸道分泌物是主要傳播途徑，需嚴格防護。

🫁

結核病敏感性

獼猴對人類結核菌高度敏感，圈養個體需定期結核病篩查，呼吸道症狀是早期警訊。

👥

社群壓力管理

獼猴有嚴格社會階層，低階個體長期受壓迫，慢性緊迫削弱免疫力，增加呼吸道感染風險。

🦍

與人類最相近

黑猩猩與人類基因相似度達 98.7%，對幾乎所有人類呼吸道病原均敏感，防疫要求最嚴格。

😷

新冠病毒風險

黑猩猩對 SARS-CoV-2 高度敏感，疫情期間需嚴格隔離，工作人員需全程佩戴口罩。

🧠

高智力與心理健康

黑猩猩智力接近人類，心理健康直接影響免疫功能，豐富化計畫對呼吸健康至關重要。

🌿

保育現況

野外僅剩約 20 萬隻，圈養個體的健康管理對保育繁殖計畫具有重大意義。

🌳

臂行需求

長臂猿需要大量臂行（盪繩）活動，活動不足導致肥胖與呼吸功能退化，是圈養最大挑戰。

🎵

鳴叫與呼吸

長臂猿以複雜鳴叫著稱，鳴叫頻率與品質是呼吸健康的重要指標，異常需立即評估。

💑

配對壓力

長臂猿為一夫一妻制，配對失敗或失去伴侶造成極大心理緊迫，削弱呼吸道免疫功能。

⚠️

瀕危現況

多種長臂猿為極度瀕危，白掌長臂猿野外僅剩數千隻，每隻圈養個體健康都至關重要。

行為豐富化與運動促進

01

攀爬與臂行設施

垂直空間與攀爬設施是靈長類最重要的運動來源，直接影響心肺功能與呼吸健康。

  1. 提供多層次攀爬架，高度至少 4～6 公尺
  2. 長臂猿需要足夠長的繩索進行臂行，至少 10 公尺
  3. 每天觀察攀爬頻率，下降代表健康或心理問題
  4. 定期更換設施位置，維持新鮮感與探索動機
02

覓食豐富化

模擬野外覓食行為，讓靈長類花費更多時間與體力獲取食物，增加活動量與深層呼吸。

  1. 將食物藏在不同高度與位置，促進攀爬移動
  2. 使用益智餵食器，延長進食時間至 2～3 小時
  3. 冷凍水果或蔬菜增加探索樂趣
  4. 每天至少 3 次豐富化活動，記錄參與度
03

社交互動管理

健康的社交環境減少慢性緊迫，直接改善免疫功能與呼吸道健康。

  1. 確保群體結構穩定，減少不必要的個體調動
  2. 監控社交互動，低階個體受壓迫需介入
  3. 長臂猿需維持穩定配對關係
  4. 定期評估個體心理健康狀態，與呼吸健康一同記錄

飲食管理與體況控制

靈長類飲食需依物種、年齡與體況個別制定，避免高糖食物

🥬

深色葉菜

羽衣甘藍、菠菜等富含維生素 C 與抗氧化劑，保護呼吸道黏膜，是飲食主體。

🫐

藍莓 / 野莓

高抗氧化，保護肺泡細胞，可作為豐富化零食，但需控制份量避免過糖。

🥦

花椰菜

蘿蔔硫素幫助排除肺部毒素，蒸熟後餵食，是靈長類呼吸道保護的重要食物。

🐟

魚類（黑猩猩）

Omega-3 減少呼吸道發炎，黑猩猩野外會捕魚，圈養可定期補充。

💊

維生素 C

靈長類無法自行合成維生素 C，缺乏削弱呼吸道免疫功能，需每日補充。

💧

充足飲水

維持呼吸道黏膜濕潤，每日提供新鮮水源，高溫期需特別確保供水。

⚠️ 飲食禁忌

🍫 巧克力（可可鹼中毒） 🍬 糖果 / 加工甜食（肥胖加速） 🧅 洋蔥 / 大蒜（溶血） 🥤 含糖飲料（代謝症候群） 🍌 香蕉過量（高糖，常見錯誤） 🥜 花生過量（黃麴毒素風險）

📊 體況管理關鍵指標

體況評分（BCS）

使用 1～9 分制，目標維持在 4～5 分，腹部明顯突出或肋骨完全看不到需立即介入

結核病定期篩查

獼猴每年至少一次結核菌素試驗，黑猩猩每年胸部 X 光，呼吸道症狀需立即篩查

人畜共通病防護

工作人員接觸靈長類需佩戴口罩與手套，有呼吸道症狀的工作人員禁止接觸

日常照護與監測指南

📹 每日觀察呼吸頻率、鼻分泌物與社交行為，社交退縮往往是呼吸道疾病的早期警訊
😷 工作人員有任何呼吸道症狀需立即停止接觸靈長類，人畜共通病風險極高
💉 每年接種流感疫苗（工作人員與靈長類），黑猩猩需特別評估新興病毒防疫
⚖️ 每月測量體重，訓練個體主動站上體重計，建立個體健康檔案
🧠 定期評估心理健康，刻板行為增加代表豐富化不足，心理緊迫直接影響呼吸道免疫
🩺 所有醫療操作需由靈長類專科獸醫師執行，結核病篩查與呼吸道評估需定期進行
⚠️ 靈長類與人類基因高度相似，人畜共通病風險極高。所有接觸需嚴格遵守生物安全規範，醫療決策由持照獸醫師執行。
